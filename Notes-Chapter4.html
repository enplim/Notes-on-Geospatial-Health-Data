The R-INLA package

The integrated nested Laplace approximation (INLA) approach is implemented in R package R-INLA. This package is not on CRAN because it uses some external C libraries that make it difficult to build the binaries.

Fitting a model using INLA requires two steps:
1. Writing the linear predictor of the model as a formula object.
2. Running the model by calling the inla() function.

Linear predictor

The syntax of the linear predictor in R-INLA is similar to the syntax used to fit linear models with the lm() function.

General form of the linear predictor formula in R-INL:
r y ~ 0 + b0 + x1 + x2 + f(i, model = "iid")

Main arguments of the inla() function

  • formula: formula object that specifies the linear predictor.
  • data: data frame that contains the data we wish to model.
  • family: string or vector of strings that indicate thelikelihood family such as gaussian, poisson, or binomial.
  • control.compute: list with the specification of several computing variables. Example: dic specifies whether the DIC of the model should be computed.
  • control.predictor: list with the specification of several predictor variables such as link or compute. The former specifies the link function of the model, and the latter indicates whether the marginal densities for the linear predictor should be computed.

Example

The example that follows demonstrates how to specify, fit a model, and inspedt the results using a real dataset and the R-INLA package.

Data

The data Surg contains the number of operations and the number of deaths in 12 hospitals performing cardiac surgery on babies. The column hospital denotes the hospital name, masked to preserve data privacy. The column n denotes the number of operations carried out in each hospital in a one-year period, and the column r denotes the number of deaths within 30 days after surgery.

Model

We specify that \(Y_i\) follows a Binomial likelihood for the number of deaths in each hospital. (\(Y_i \sim Binomial(n_i, p_i), i = 1, ..., 12\))

We also assume that the mortality rates across hospitals are similar in some way, and specify a random effects model for the true mortality rates \(p_i\) (\(logit(p_i) = \alpha + u_i, u_i \sim N(0, \sigma^2)\)).

The default prior for the precision of the random effects \(u_i\) is \(1/\sigma^2 \sim \Gamma(1, 5 \times 10^{-5})\). This can be changed, for example, by setting a penalized complexity (PC) prior on the standard deviation \(\sigma\):

prior.prec <- list(prec = list(prior = "pc.prec",
                               param = c(1, 0.01)))

Translating the model into R code:

formula <- r ~ f(hospital, model = "iid", hyper = prior.prec)

Calling the inla() function:

res <- inla(
  formula,
  data = Surg,
  family = "binomial",
  Ntrials = n,
  control.predictor = list(compute = TRUE),
  control.compute = list(dic = TRUE, return.marginals.predictor = TRUE)
)
